# Cutline

Draw basketball plays beat by beat and watch them run on a 3D court, quiz yourself on the reads
from a player's eyes, and export clips. Live at https://janetlee.me/cutline/

Plain static site (ES modules, three.js vendored). Run locally with `python3 -m http.server` and open
http://localhost:8000/. Spun out of [Dance Studio](https://github.com/janetcl/dance-studio).
